# 정책위원회 in 홍성

2026 서울특별시사회복지사협회 정책위원회 정기회의 및 워크숍(2026. 8. 21.~22., 충남 홍성·보령) 안내 페이지.
빌드 도구가 없는 정적 페이지 한 장 + 참석 회신을 받는 Apps Script 백엔드로 구성됩니다.

```
index.html              페이지 전체 (HTML·CSS·JS 한 파일)
apps-script/Code.gs     구글시트에 붙이는 백엔드
README.md               이 문서
```

## 무엇을 하는 페이지인가

- 개요 · 일정 · 장소 · 참석자 현황 네 항목을 한 페이지에 담습니다.
- 참석자 현황에서 각자 `수정`을 눌러 **참석 여부**와 **도착 시각 · 교통편 · 열차 시각**을 직접 입력합니다.
- 입력값은 구글시트에 저장되고, 페이지를 열 때마다 시트를 읽어와 집계와 후발 도착 목록을 다시 계산합니다.

`API_URL`을 비워 두면 백엔드 없이도 동작합니다. 이때 입력값은 **입력한 사람의 브라우저에만** 남습니다.

## 1단계 — GitHub에 올리기

```
cd ~/sasw-workshop
```
```
git init -b main
```
```
git add . && git commit -m "정책위원회 워크숍 안내 페이지"
```
```
gh repo create sasw-workshop --public --source=. --push
```

`gh`가 없으면 GitHub에서 빈 저장소를 만든 뒤 아래를 실행합니다.

```
git remote add origin https://github.com/kosuk1231/sasw-workshop.git && git push -u origin main
```

## 2단계 — Vercel에 배포

1. Vercel에서 **Add New… > Project**, 방금 만든 저장소를 Import
2. **Framework Preset** 은 `Other`
3. **Build Command** 와 **Output Directory** 는 비워 둠
4. Deploy

`apps-script` 폴더는 배포에 영향을 주지 않습니다. 정적 파일만 서빙됩니다.

## 3단계 — 구글시트와 Apps Script 준비

1. 구글 드라이브에서 새 **스프레드시트**를 만들고 이름을 `2026 정책위원회 워크숍 회신` 등으로 지정
2. 시트 상단 메뉴 **확장 프로그램 > Apps Script**
3. 기본으로 열린 `코드.gs` 내용을 모두 지우고 `apps-script/Code.gs` 전체를 붙여넣기
4. 저장(⌘S) 후 함수 목록에서 **`setup`** 선택하고 **실행**
   - 권한 승인 창이 뜹니다. `고급 > 안전하지 않은 페이지로 이동`을 눌러 승인합니다.
   - 시트에 `응답` 탭과 머리글이 생기면 정상입니다.
5. 오른쪽 위 **배포 > 새 배포**
   - 유형 선택: **웹 앱**
   - 설명: `v1`
   - **실행 계정: 나**
   - **액세스 권한: 모든 사용자**  ← 이걸 놓치면 페이지에서 읽지 못합니다
6. 배포 후 나오는 **웹 앱 URL**을 복사합니다. `https://script.google.com/macros/s/AKfy.../exec` 형태입니다.

## 4단계 — 페이지에 URL 연결

`index.html` 을 열어 `<script>` 안 위쪽의 한 줄만 고칩니다.

```js
var API_URL = "https://script.google.com/macros/s/AKfy.../exec";
```

커밋하고 푸시하면 Vercel이 자동으로 다시 배포합니다.

```
git add index.html && git commit -m "회신 저장 연결" && git push
```

페이지를 새로 열었을 때 참석자 현황 상단 칩이 **`n명 회신 반영`** 으로 바뀌면 연결된 것입니다.
`연결 실패` 로 나오면 5단계를 확인하세요.

## 5단계 — 확인

| 증상 | 확인할 것 |
|---|---|
| `연결 실패` | 배포 시 **액세스 권한이 '모든 사용자'** 인지. 권한을 바꿨으면 **새 배포**를 다시 해야 적용됩니다 |
| 저장은 되는데 목록에 안 보임 | 시트 `응답` 탭 이름이 그대로인지. `Code.gs` 의 `SHEET_NAME` 과 같아야 합니다 |
| 도착 시각이 날짜로 바뀜 | `setup` 을 한 번 실행하면 F·I 열이 텍스트 서식으로 고정됩니다 |
| 코드 수정 후 반영 안 됨 | Apps Script는 **배포 > 배포 관리 > 편집 > 버전 '새 버전'** 으로 갱신해야 합니다 |

편집기에서 **`selfTest`** 를 실행하면 저장·조회가 한 번에 점검됩니다. 점검 후 시트에서 `id 999` 행은 지워 주세요.

## 내용 수정

### 명단

`index.html` 의 `BASE` 배열을 고칩니다. `id` 는 회신 저장의 기준이므로 **한 번 정한 뒤에는 바꾸지 마세요.**

```js
{id:9, name:"김유리", group:"운영위원", org:"서대문구재가노인복지기관", title:"관장", status:"tbd"},
```

`status` 는 네 가지입니다.

| 값 | 표시 | 색 |
|---|---|---|
| `full` | 전일정 참석 | 민트 |
| `part` | 부분 참석 | 피치 |
| `tbd` | 확인 중 | 슬레이트 |
| `no` | 불참 | 로즈 |

`part` 인 사람은 `day`(1일차/2일차) · `arr`(HH:MM) · `transport`(기차/자차/기타/미정) · `from`(승차역) · `dep`(열차 출발) · `note` 를 함께 적을 수 있습니다. 시트에 회신이 들어오면 시트 값이 `BASE` 값을 덮어씁니다.

### 일정 · 장소

`index.html` 본문의 `<section id="s2">`(일정), `<section id="s3">`(장소)에서 해당 줄을 직접 고칩니다.

- 일정 항목: `<div class="ev">…</div>`
- 이동 구간: `<div class="hop car">…</div>` — 열차 구간은 `car` 클래스를 뺍니다
- 장소 카드: `<article class="pc">…</article>` — 대표 장소는 `pc key`
